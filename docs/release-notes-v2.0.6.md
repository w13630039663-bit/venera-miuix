# venera-miuix v2.0.6

这一版都在收拾真机上发现的"看着不对劲"：按下去没反应、转圈停不下来、图站在手机上打不开、
动画硬跳一块。都是白话，细节账在仓库的交接手册里。

## 图廊

- **Gelbooru 的日/周 / 月 / 年排行在手机上终于能出图了**。站方给的日期写法，和手机自带的日历库对不上，
  只有真机会坏 —— 不是你没配密钥。
- **Gelbooru 可以选"具体哪一期"**，历史月份也框得出来了。
- 搜索展开、收起改成**同一块面在长高 / 缩回**（以前是硬换一块东西）。
- **每一张能点开的图片，按下去都有反馈**（以前一半按下去纹丝不动，读起来像"这张点不开"）。
- 搜索**失败不再把你退回首页**；屏上会说清"这一轮哪条腿没跑起来"，账号被拒时直接给去设置页的出口。
- **收起键盘不再顺手把搜索区收起来**（按你说的）。
- 结果态那一行改挂在右边不挡图的位置；大图页飞入动画带出四枚白角的问题修掉了。
- 图廊首页也能**换头图**了，和设置页那张各存各的、互不影响。
- 底栏**选中那个图标跟着壁纸取色**（以前是写死的一枚蓝）。
- 最近搜索改成**点两下才删**（第一下选中、第二下才真删），× 更好按；已选条件那一排维持原样。
- 断网时"这一轮少了什么"在**已经铺着缓存内容**的屏上也会说，不再闷着。

## 漫画与界面

- 搜索翻页转圈时改一个字就**永久卡住**的问题修好了。
- 详情页那排动作按钮配色收干净：只有收藏、点赞两枚带身份色，按下去那圈底色不再半透明发虚。
- 下载并发滑块**改完当场生效**（以前是同一次运行里怎么拖都不生效的假开关）；追更有了入口；
  封面取不到图会说、并给真能重试的按钮。
- 探索页撤掉四行光杆标题；横向滑动的行给出"后面还有"的渐隐证据；列表卡减负、大图页补出口。
- 平板 / 大屏：统计、源管理、分类探索三页不再整屏铺满，内容收到一条舒适宽度里。**手机档一个字没动**。
- 摘掉开发期的诊断日志（那种"每次点图片都往本机写一份"的）。

## 升级

签名与 v2.0 / v2.0.2 / v2.0.3 / v2.0.4 / v2.0.5 是**同一把正式证书**
（SHA-256 `62b89c491bd6fca41beb25f0baafc80cfad865397302d37694df1fda6a69846b`），
**直接覆盖安装即可**，收藏、历史、下载、图廊数据都在，不用卸载。
系统要求 Android 13（API 33）及以上，目标 API 37。`versionCode` 2006、`versionName` 2.0.6。

本版默认档改了三项（只影响**从没设过该项**的新安装）：排版 = 美漫·左至右、底栏 = 液态玻璃悬浮、
界面风格 = MD3 取色。备份与同步可以多一档"带上漫画源账号"，默认不带。

⚠️ 上面那两句是 **v2.0.5 已经发出去过**的内容，本文件为了"从 v2.0.4 一路读到 v2.0.6"才留在这里；
**线上那份发布正文里没有它们**（正文只写本版新增的那一格），别照本文件念成"这版又改了一次默认档"。
