# venera-miuix v2.0.8

这版接着收拾上一版留下的那几格"设了头图之后不对劲"的地方。**直接覆盖安装就行**，收藏、历史、
下载好的漫画和画廊数据都还在（`versionCode` 2008）。

## 修好了

- **设过头图的那几页（设置首页、设置各子页、画廊首页），页顶那幅大标题终于跟其他页对齐了**：
  字号、字重、左边距、顶边都改成跟系统顶栏同一份取值，切页时标题不再跳上跳下。
  颜色**故意**留着白色 —— 头图是大家随手选的，亮度不可控，换成深色字压亮图会直接读不出。
- **头图页往上滑之后，顶栏那排按钮不再"歪上去"**。真机上量出来的成因是顶栏被压扁时整棵内容被往上顶，
  所以症状出现在按钮那一排，而标题其实一直是对的位置 —— 前两轮换基准都白改了。
- **设了头图的页面不再有多余的回弹**。而且这一格从前"设了等于没设"：写的是已经废弃的那个开关，
  换成新开关才真关掉。
- **画廊首页的头图通铺到边**，左右不再各留一道。

## 知道就好

- 上面三格都是**按源码与真机像素读数改的**，改完这几格还没在真机复量（本机没连设备）：按钮行是否真回到
  正位、关掉回弹之后的手感、异形屏与手势导航下的头图边距。装完觉得哪一屏不对，请直说是哪一屏。
- Windows 桌面版还是实验性质，**和这个安装包无关**。
- Gelbooru 仍要自己填 API 账号才能取图；以图搜图仍要自己的 SauceNAO key。
