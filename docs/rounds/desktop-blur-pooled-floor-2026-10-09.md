# 批 73 · 跨轮地板与最低观测数（2026-10-09）

## 0. 这一批补的那一层

批 72 让每轮**独立**下判词，跑出来 `各轮=量不出/量得出/量不出 一致=否` —— 那句话本身是对的，
但**为什么**会不一致，读数没说：每轮的地板只由**两枚**估计算，而两枚数的散布可以正好是 0
（轮 2 就是 `地板=0.00ms` ⇒ 一丝差值都算"量得出"）。
⇒ 本批把地板做成**跨轮的**：并堆的是**每轮产出的那两对估计**（同一件事的 2N 枚观测），
**绝不是各轮的相**（并相就废掉 ㉑ 的"每轮独立一本账"，也又把"几轮各自判了什么"埋回一堆数里）；
并且设一枚**最低观测数**：少于 4 枚估计（= 少于两轮）就不下判，只念「判定=轮数不够」。
那枚 4 不是拍的门槛，是"两枚数算不出散布"这件事本身。`app/` 零改动，屏上行为零改动。

## 1. 尺子（21→22）

㉒ 总判并堆估计而轮数不够就不许判，钉六件事：那串估计存在且住在轮循环**外面**（次序钉）、
每轮把**两对都**交出去（`pairEstimates.add(pairA)` + `(pairB)`）、少于 4 枚那一支必须存在、
跨轮地板取极差（`poolFloor = pairEstimates.max() - pairEstimates.min()`）、总判念得出吃了几枚估计、
**「判定=轮数不够」那一行里不许出现"量得出"**（不够只能说不清，不能说不贵）。

扰动 2 笔各红 ㉒：P1 每轮只交一枚（交的是那一轮两对的平均 ⇒ 组内散布从此看不见）、
P2 把最低观测数改成 `< 0`（两枚估计也照样算极差下判 = 批 72 轮 2 那形状）。
还原后全量 **784 判据 / 100 类 / 0 失败**（三方口径一致），目录 0 处漂移，窗口残留 0。

## 2. 量到了什么（`-Pstep=400 -Prounds=4`，留档 `_qa/b73_rounds4.log`）

```
轮1 差值|p95|=0.29ms  本轮地板=2.66ms  量不出
轮2 差值|p95|=0.05ms  本轮地板=0.10ms  量不出
轮3 差值|p95|=0.03ms  本轮地板=0.01ms  量得出
轮4 差值|p95|=0.02ms  本轮地板=0.01ms  量得出
S09C_总判 轮数=4 各轮=量不出/量不出/量得出/量得出 一致=否 枚估计=8 跨轮地板=2.66ms 跨轮均值=−0.08ms
        判定=没盖过跨轮地板（这一格今天仍未知）
```

四条分开讲：

- **8 枚观测、跨轮地板 2.66ms、均值 −0.08ms ⇒ 仍"没盖过"** —— 这一格至今未定，而这句现在是**读数自己念的**，
  不是我对着几行数字 eyeball 的。
- ⚠️ **极差对单个异常值极敏感**：那 2.66ms 整笔是轮 1 的一枚野估计撑起来的（其余 7 枚都落在 ±0.1ms 量级）。
  所以"地板 2.66ms"读出来的是"**有一轮出过一格野数**"，而不是"这把尺子分辨不了 0.1ms"。
  下一版该换**分位距**或对单枚极值稳健的散布度量 —— 但那是**换估计量**，不能靠删掉那枚野数（挑数就是造假）。
- 形状上看：后两轮的差值都在 −0.02~−0.05ms（糊那一层略"快"，落在噪声里），轮 1 那轮才是异常者。
  ⚠️ 这**不构成结论**，只是描述形状；不许写成"已验无代价"，也不许写成"已验很贵"。
- 各轮说法仍不一致（量不出×2 / 量得出×2）⇒ 总判那句"别引用一轮的数"照旧生效。
