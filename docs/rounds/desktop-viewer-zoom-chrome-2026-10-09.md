# 第五十五批：大图那一屏念得出放大到几倍（2026-10-09）

## 1. 这一格补的是什么

那一屏今天只有「第 N / M 张」：滚轮滚一下到底生没生效，屏上看不出来 —— 倍数只住在 `ZoomState` 里，
而它出声的地方只有一处：取证种子那条路（`D_放大种子 给=… 用=…`）。手册 §17 那条
「滚轮真滚一下图动不动 —— 仍未过」缺的正是这个：**用户手上没有 stdout**。

于是加两样：右下角一句「放大 2.5x」与一枚「回到原大小」。没放大时整格不摆。

## 2. 落地面

| 件 | 做什么 |
| --- | --- |
| `DesktopGalleryViewerPolicy.kt` | `desktopZoomChrome(scale)`：一位小数、贴着 1 的抖动（≤1.04）算没放大、非有限值与 0 以下一律不摆 |
| `DesktopGalleryViewer.kt` | **拆成两格**：`DesktopViewerStage`（缩放层：`.zoomable` 与图本身）与外面那层（覆盖层三格：失败那句 / 页码 / 倍数与复位） |

## 3. 图证抓到的一条（批 50 就带着的）

第一版把那两格摆在**带 `.zoomable` 的那枚 `Box` 里面**，`-PviewerZoom=2.5` 那一帧拍到的是：
图放大着，而右下角与底部**整屏没有那两格** —— `.zoomable` 的变换吃的是它那一格的整棵子树，
放大两倍半就把覆盖层一起推出屏外。**728 颗判据当时全绿**（单测从不排版），只有像素抓得到。

同一帧顺带量到一条比本批更早的：**页码从批 50 起就住在缩放层里**，也就是"一放大页码就没了"，
这一批把它一起搬出来了。修法是分家而不是给覆盖层反算变换 —— 反算等于把库的缩放实现细节
（pivot、offset、graphicsLayer 的顺序）抄进我们这侧，库一升级就对不上。

## 4. 判据：新增 7 颗 ⇒ 728 颗 / 94 类 / 0 失败

① 纯函数五档（1.0 / 1.04 / 2.4 / 顶格 / 0·负·NaN·无穷）；② 那一格吃**活的** `zoomState.scale`
且算式全树只一处（定义 + 调用 = 2 次）；③ 没放大整格不摆；④ 那枚按钮走
`scope.launch { zoomState.reset() }`（`reset()` 是 suspend）；⑤ 复位只走库那颗 `reset()`
（恰好两处：翻页与按钮），`changeScale(1f)` 当复位记 0 次 —— 它只改倍数，拖偏过的位移回不来；
⑥ 与页码各占一角（`BottomEnd` / `BottomCenter`）且页码那句没被顺手改掉；
⑦ **覆盖层不许住在缩放层里**（顺序钉：`DesktopViewerStage(` 在前、`.zoomable(` 在后）。

扰动 7 笔各红各的尺子：1.0 也摆 / 改吃种子那个数 / 撤掉「放没放大」那道闸 / 翻页那处改用
`changeScale(1f)` / 那一格挪去与页码同角 / 按钮改用 `changeScale(1f)` / 把 `DesktopViewerStage`
整颗搬到文件开头（证明 ⑦ 是**顺序**尺子而不是存在性尺子）。
另外记一条：**"把覆盖层塞回变换里"那一版今天多半编译不过**（`scope` 与 `selection` 不在参数表里），
所以 ⑦ 与图证两道一起防，不假装单条尺子能盖住全部。

## 5. 两帧读数（同一颗种子，两种形状）

| 跑法 | stdout | 屏上 |
| --- | --- | --- |
| `-Pdetail=1 -PviewerZoom=2.5` | `D_放大种子 给=2.5 用=2.5`、`D_落点 … 浮层=开 查看器=开 种子=detail+viewerZoom` | 图放大 2.5 倍，右下角「放大 2.5x」+「回到原大小」，底部页码在 |
| `-Pdetail=1`（不带倍数） | 没有 `D_放大种子` 那行 | 1 倍，右下角**空**（整格不摆），底部页码在 |

⚠️ 滚轮那一路仍**没有 agent 侧的凭据**（禁鼠标）：这一格把"看不看得见"解决了，
"滚一下会不会变"仍归 §17 那条只能用户手动过的账 —— 现在它变成一眼的事：滚一下，右下角那个数跟着走就是通了。

第三帧拍的是**交付包本体**（`_qa/desktop-exe-2026-10-09-b51/`，换成本轮那颗 jar 之后）：
`--viewer-zoom=3.2` 起窗 ⇒ stdout `D_放大种子 给=3.2 用=3.2`，屏上「放大 3.2x」+「回到原大小」+ 页码三格都在。
这一跑同时验掉一条：换 jar 时那份 `app/*.cfg` 跟着换是对的（cfg 按文件名列 classpath，换错就起不来）。
