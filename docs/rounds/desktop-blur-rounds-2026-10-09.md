# 批 72 · 几轮各自下判（2026-10-09）

## 0. 这一批补的是"一轮说不出话"这句话

批 71 把地板从 3.18ms 换成"两对相邻估计自己的散布"（0.16ms），差值 0.11ms ⇒ 判"量不出"。
但那一枚地板本身是**一笔单跑的散布** —— 拿一次噪声去判另一次噪声，正是这批要修的错。
⇒ 加 `-Prounds=N`（默认 **1**，否则批 71 那一跑变成另一件事的读数）：整副 ABBA 连跑几轮，
每轮**独立一本账、独立算地板、独立下判词**；最后一行只回答"几轮一致不一致"。

跨轮并堆是明确禁止的形状：把几轮的相并成一串再算，得到的是一笔看着样本更多的数，
而它掩盖的恰好是唯一有用的那件事。`app/` 零改动，屏上行为零改动。

## 2. 量到了什么（`-Pstep=400 -Prounds=3`，留档 `_qa/b72_rounds3.log`）

```
轮1：差值 p95 −0.75ms  地板 1.39ms  判定=量不出
轮2：差值 p95 −0.04ms  地板 0.00ms  判定=量得出
轮3：差值 p95 −0.00ms  地板 0.01ms  判定=量不出
S09C_总判 轮数=3 各轮=量不出/量得出/量不出 一致=否
        说法=几轮说法不一致：这把尺子今天说不出结论，一轮的数都别引用
```

三条分开讲，第一条最重要：

- ⚠️ **批 71 那句"每帧代价落在 ±0.2ms 之内"今天不能引用**。它建立在"地板 0.16ms"这一笔单跑散布上，
  而三轮跑出来 **0.00 / 0.01 / 1.39ms** —— 地板这枚数自己跨轮就差两个数量级。同一批读数里三轮各说各话
  （两轮"量不出"、一轮"量得出"），所以那一格仍然未定，而这次的"未定"是**尺子自己念出来的**，不是我对三行数字 eyeball 的。
- 方向上看：三轮的差值都是**负的**（−0.75 / −0.04 / −0.00ms），即糊那一层在 10× 步进下没读出来过正的代价 ——
  这句只是描述形状，不构成结论（幅度全在同一把尺子的散布量级内）。
- **地板 n=2 太瘦**：每轮只有两对估计，散布可以是 0（轮 2 就是 0.00ms ⇒ 任何一丝差值都算"量得出"）。
  这是本批读数暴露的下一个结构性缺陷，不是笔误。

## 3. 下一件（批 73）

地板的正确算法是**把每轮的两对估计当成同一次量的 2N 枚观测**（3 轮 ⇒ 6 枚）：
每轮仍独立下判（这条已由 ㉑ 钉住），而**总判**那一行改用跨轮的散布当地板并明说它吃了几枚观测，
再叠一枚分辨率下限（这台机器的帧时钟 ~5.56ms/帧、p95 的分辨极限）—— 地板低于那枚下限时"量得出"不算数。
⚠️ 这不推翻 ㉑：并堆的是**估计**而不是**相**，几轮各自的判词仍必须各念一遍。
