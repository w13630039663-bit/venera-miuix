## 二、`.phead` 段头（本批）

### 每一簇里念的都是真数

| 位置 | 稿上 | 这一版 |
|---|---|---|
| 主标题 | 图库 · 今日 | 同文案 |
| 子标题 | 10-03 · 三站并行 · 每站 12s 预算 | `Daily.date` 原值 · 三站并行 · 每站 `${budgetLabel}` 预算 |
| chips | 东方Project / 少女 / 4k / +6（手摆占位词） | **当页标签频次前 4** + `+N`（剩余 distinct 数），`desktopTopTags` |
| 换一批 | 一枚刷新小钮 | 同枚，背后是真动作（换种子本地重排，不再联网） |

三处判断值得单说：

1. **日期写全 `yyyy-MM-dd` 而不是稿的 `10-03`** —— `Daily.date` 实际是**昨日**
   （`GalleryDailyFeed.yesterdayString()`），短写看着像"今天"。
2. **「三站并行」描述的是请求形状**（`loadDaily` 里三笔 `async`），不是"三站都答上了"；
   结果读数归状态栏。两句话各说各的，不许混。
3. **分段控件三档只有「推荐」真的有东西**。另两档（最新 / 排行）在 pane 里就是两行未实现行，
   所以：**点它们不切选中项，而是把原因说出来**，原因串**逐字复用 pane 注册表**的 `reason`
   （`desktopGalleryHomeRows()`）—— 写第二份就会漂。由判据「段头与 pane 对同一份六项表说话」钉住。

## 三、`.status` 状态栏（本批）

新件 `DesktopGalleryStatusBar.kt`。三条读数**各有出处**：

| 读数 | 出处 |
|---|---|
| `3 站 · 2 给内容 · 1 缺席` | `Daily.pools.size` 与 `Daily.failures.size` |
| `本次取数 X 前` | 取数**完成那一刻**的时刻戳（新增在 `DailyState.Ready` 上） |
| `每站 12s 预算 …` | `GalleryDailyFeed.PER_SITE_TIMEOUT_MS` 现算，**不写死 12** |
| `已滤掉：…` | 从旧页脚搬来（那一行正文本批删除） |

三处判断：

1. **「X 前」挂了一支 30s 心跳**。只看组合期快照会说谎：不重组时"刚刚"会一直挂着，
   半小时后它还在说"刚刚" —— 那不是旧读数，是假读数。
2. **站点数写阿拉伯数字**，不照稿写汉字「三」：要写汉字就得先造一张 数字→汉字 表，
   而站点数是从 `pools.size` 来的 —— 让 UI 念的字必定等于实际跑了几个站。
3. **右侧那枚 `Ctrl K` 键帽不画**（同标题栏：桌面没有全局快捷键链，画了就是假开关）。

位置差量：稿把 `.status` 放在 `.page` **之外**（`.page` 自己 `padding:0 24px`，状态栏是另一套
`padding:0 12px` 的全宽条）。桌面没有 `.main`/`.page` 那层结构，所以画在 pane 列最底部、
吃 `weight(1f)` 那层**之外** —— 视觉位置等价。另：稿 `box-sizing:border-box` 那枚 24px **含**顶边
那条 1px，所以内容行取 24−1，不然总高 25 会挤掉一格。

## 四、顺手抓到的一处真漏网：色值写了字面量

色板扫描器（`DesktopSurfaceLiterals`）的**前缀表白名单只登记了 surface 四档 + 三处补丁**，
于是**文字档整块是盲区**：`DesktopFollowedArtistsPane.kt:110` 那句
`private val MetaText = Color(0xFF8B8B8B)`（`DesktopTheme.TextTertiary` 的同值重写）
**从落成那天起就没被扫到**。

按本仓既定的**执行顺序硬约束**办：先把那处改成引主题，**再**补前缀表
（顺序反了就是"判据自己先崩"）。本批把前缀表从 8 条扩到 15 条 ——
文字三档（`FFFFFFFF` / `A0A0A0` / `8B8B8B`）、强调与半透明（`CBB6FF` / `D6463C` / `3A2A55` / `80000000`）、
beni chip 两枚（`4A2220` / `FFB4A8`）全部登记。

> 未登记但存在的一处：`MicaProbe.kt` 的 `0x00200000`。那是探针文件的位标志、不是 `Color(...)`，
> 不属这条尺子的管辖面。
