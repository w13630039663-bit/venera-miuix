# 批 65 · 覆盖层在动那一档 + 把批 64 的差值算法改判（2026-10-09）

## 1. 两件产物

1. **生产那一形终于被量到了**：批 64 量的是"墙自己在动"（慢滚），而生产里墙是静帧、动图在**浮层**里播
   （批 51）。给同一架探针加一档 `-Poverlay=anim`（覆盖层每帧换内容），默认仍是静 ⇒ 批 64 那七笔读数不换对象。
2. **量具的一处系统性偏置被抓出来并改判了批 64 的一条结论**：三相设计里差值拿**相 0** 当基线，
   而这台机器的**相 0 恒最慢**。改成**四相配对**（不糊→糊→不糊→糊）后，重载那一档的"+1.34~+1.99ms"不复现。

## 2. 偏置是怎么露出来的

批 65 头两跑（三相版，`-Poverlay=anim`）念出的差值是 **−1.06ms 与 −0.68ms** —— "糊比不糊快 1ms"。
这不是物理，是算法：九笔历史读数里相 0 的 p95 一律高于相 2（6.11/5.70、6.32/5.70、5.80/5.72、
7.81/5.65、6.75/5.66、6.37/5.64……），**方向全一致**。也就是说"糊 vs 相 0"里混着"相 0 vs 相 2"这笔序偏置，
而它正好**偏袒糊**（把差值往负里推）。

⇒ 改法不是"再减一个修正项"，而是**把设计改成配对**：两相不糊、两相糊，差值从两组均值算，
序偏置在两组里各占一半就抵消。另念两行让这类事以后自己出声：

- `S09C_回退 两相不糊相比（序偏置）` —— 两枚同条件（都不糊）相自己相比，那就是这把尺子的漂移；
- `S09C_重复 两相糊相比` —— 糊组内两枚相自己相比，若它比组间差还大，那组间差就不许当结论。

## 4. 三条结论（以及撤下的一条）

1. **覆盖层每帧换内容时，身后那层糊没有每帧重算**：两种形状下差值都是 −0.01~−0.43ms，
   与"两枚不糊相自己的漂移"（−0.18~−0.87ms）同量级同方向 ⇒ 落在噪声里。
   生产含义：大图里动图在播时，那层 18dp 的糊是**一次性的钱**，不是每帧的钱。批 63 那一档可以放心留着。
2. **稳态慢滚那一档仍然量不出代价**（与批 64 同判，配对口径下更干净）。
3. ⚠️ **撤下批 64 §3/§6 那句"10× 重载尾巴 +1.34~+1.99ms（1.16~1.23×）三跑同向"**：
   配对版两跑**反号**（+1.76 / −0.42），而糊组内重复性 −1.30 / −2.73ms **比组间差还大**
   ⇒ 重载那一档这把尺子的噪声大于信号，代价**未定**（不是"贵"，也不是"便宜"）。
   那句"三跑同向"之所以看着同向，正是因为三笔都拿同一个慢基线去比。
4. 依旧**不换实现**、不改屏上那两句、交付包不重打（屏上行为零改动）。

## 7. 这一批留下的一条通用规矩

**同一台机器上"第一相总是最慢"是常态而不是例外** ⇒ 任何"前后两相各跑一次再相减"的量法都要先问：
基线那一相是不是**恰好**是刚起步那一相。要么配对（同条件各占两组），要么把"两枚同条件相自己相比"
念成一行读数。**批 64 那三笔"同向"就是同一个慢基线造出来的假一致。**
