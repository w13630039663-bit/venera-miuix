这版丢掉我自己那套配色，改成照画廊现在这一套长：浅色暖粉灰的色调台阶分层（卡底 surfaceContainerHigh #F6E4E2、块内再低一档）、 大圆角、卡面不补描边、图上胶囊一律 GalleryCornerPill 那一颗（#1F1F1F @ 0.80 + #F5F5F5、10sp、内缩 6dp）、 顶栏与底栏都是玻璃圆座（视觉 40 / 触达 48）、相关图片直接走首页那颗瀑布流（真实比例 + Sink 按压）。 数据是假数据（字段与形状照真接口，画师名/标题/标签是编的），为的是看密度与层次，不是看内容。

三 · 首屏高度预算（393dp 宽）

块高口径
状态栏 inset≈30dp系统给，页面不写死
图区（含页码与缩略把手）≤474dp封顶式 min(按比例实高, 屏宽 × 1.2)
画师 + 标题行64dp头像 40 + 上下各 12
标签头（收起一行）44dp胶囊 32 + 上下 6
缩略条≈72dp与图区比例档共用 12dp 间距
操作栏占位76dpbottomBarClearance，读 LocalBottomBarClearance
⇒ 首屏落点：图 + 画师 + 标题 + 标签头 + 缩略条露头；评论与相关图片在第二屏（对得上"继续向下滚动就能看标签与推荐"）。

四 · 明确不做

不做发评论 / 按表情 / 回复三个写口没有写口就不摆输入框，摆了就是假按钮
不做评论区"算法排序 / 最热评论"站方只给时间序，排序是我们编的
不做相关图片的无限加载一次拿一屏，触底再要下一页（与首页同一条节流）
不做独立 Activity 承载这一屏跨 Activity 会把自有 chrome 截进共享元素飞行体

稿内 hex 是浅色档的近似观感（锚点取自现量的 #F6E4E2 / #EFDCD5），落地一律吃 VeneraColorTokens 的语义槽位； 图标全部线性 SVG（不用 emoji 当图标）；可点处触达位 ≥48dp；动效走 VeneraMotionTokens； 数据是假数据，字段形状照真接口，画师名 / 标题 / 标签为编造。
