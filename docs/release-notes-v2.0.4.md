## 本版新增：查到新版本可以直接在应用里装了

入口在 **设置 → 关于 → 「检查更新」**；想让它自己提醒你，把同一张卡里的**「启动时检查更新」**打开（与旧版一致，默认关）。检测到新版后那张弹窗现在有三态：**问**（要不要更新）、**下**（进度进通知栏）、**装**（唤起系统安装页）。

- 下载**边写盘边算 SHA-256**，写完与 GitHub 在产物上给的 `sha256:` 逐字比对，**对不上就不交给安装器** —— 这也是「加速镜像」能被安全使用的前提：换了别人的域名，校验的仍然是同一份哈希。
- **官方直链优先**，失败再按候选表回退加速镜像；**没拿到哈希就直接塌成只剩官方**（没校验就不该把十几 MB 的可执行包交给第三方域名）。
- 失败时念的是**实际读数**（哪个候选域名、什么 HTTP 码），不会把一次断网播报成「已是最新版本」。
- 装包那一步的三种去处各有明确说法：未授予「安装未知应用」时停在引导页而不是无声无息；**签名与本机已装版本不同时会先说「需先卸载并备份」**，而不是让你去猜系统那句「应用未安装」。
- 「以后再说」按**版本号**记账：跳过的是这一版，出了更高一版仍会再问。
- 明确不做（不是漏做）：前台服务（**把 App 划掉下载就中断**，重进可重试）、断点续传、不经确认的自动安装。

## 本版修复

**1. 画廊「关于这张图」面板：打开后整块点不动，以及全屏时下拉快速上下跳**

两条症状查下来是同一条环的两个出口：半模态的面板高度由内容量出来，而内容可用高度又由面板给 —— 内容异步长高（标签译文回填）就会让两边互相推着走。

- 面板改成**固定高度**（屏高减去顶部预留的 140dp），展开锚点从此与内容高度无关；标签与译文的回填只影响面板内部滚动。
- 修上一轮的判据挂错了位置：`Modifier.nestedScroll` 的语义是**向祖先注册**，而它从前挂在滚动容器的内侧，于是那条「内容到底后残余位移不该交给面板」的判据**一次都没被调用过**（真机日志 0 条即为证）。现已挪到 `verticalScroll` 之外。
- 加了一枚**落定看门狗**：库里那个拖动标志有一个没有兜底的赋值点，一旦卡住，面板就声称自己在动画中、并在最早那段把每一笔按下都吃掉 —— 表现正是「什么内容都点不了、长按也没反应，但拖得动」。内容到位后若面板声称已展开却仍卡着、且手指不在屏上，就重申一次落定（零距离动画，画面不动）。

⚠️ **观感取舍**：面板现在固定占大半屏，**不再有半开档**（内容很少时也是这样）。这是为稳定性换的选择，不是回归。

**2. 画廊墙滚动时的抖动**：掐掉每帧重组每张可见卡的自激环。

**3. 画廊切走再切回不再被按回顶部**：位置保留（「已经回过顶」那枚凭据从前存在会被重建的地方）。

**4. 大图页底部工具条少一枚按钮时，「关于这张图」不再挪位。**

**5. 封面 → 详情页的共享元素转场不再把自家界面截进飞行体**：起点被自有顶栏/底栏压住时先让位两帧再截帧，底栏那层覆盖吃同一枚让位开关。

**6. 探索页两处被迁移丢掉的东西补回**：随机窗口（`randomNumber`）恢复；榜档改为在「本源分类」里**逐档成入口**，标签用源自己给的档名（例如禁漫天堂的「日排行」）。

## 本版增强

- **长按画廊墙上一张卡**出五项动作表：查看详情 / 收藏（或取消收藏）/ 复制图片地址 / 分享图片 / 查看画师「某某」。
- **「关于这张图」里的画师卡长按**可复制画师名或**屏蔽该画师**。
- 标签药丸在「标签即内容」的四处放开两行，组件默认值仍是单行（别处不受影响）。
- 画师头像三处收成同一颗件，默认档与退路（字母座）字号统一。
- miuix 组件的字阶改吃本仓那一份表 —— 从前两边是「巧合式相等」，现在改一处两边一起动。

## 本版工程改动（你在界面上看不到，但决定了后面还能不能改）

- **三颗共享存储的原子写换掉了 `File.renameTo`**（画廊收藏 / 画师关注名单 / 头像地址档，改成 `Files.move(..., REPLACE_EXISTING)`）。Android 侧行为不变；但这三颗同时被桌面端复用，而 `renameTo` 在 Windows 上遇到目标已存在**只返回 false 而不替换**，于是桌面侧从第二笔起整份丢档。
- **判据层从 109 个文件 / 818 用例增加到 116 个文件 / 886 用例**，全部纯 JVM、不需要设备（发布前复跑：0 失败 0 错误 0 跳过）。
- 「关于这张图」那一族的**诊断探针仍在代码里**（只打 logcat、一行都不上屏）：成因已由真机读数定死，探针按清单在下一版撤除。

## 桌面端（Windows 实验线，与本安装包无关）

本 tag 只含一颗桌面改动：收藏域与搜索域从「坦白页」接成真页面。桌面线其余进展（离线译名词典进包、pixiv 头像、连播与预取开关等）**此刻仍在开发机工作区未提交，不进本 tag 的源码**。桌面模块不产出 Android 包，装本 APK 看不到任何变化 —— 写在这里只为说明本 tag 的源码里包含了什么。

## 请重点验证

1. 通知栏进度是否真在动；下载**完成态点一下**能否直接落到系统安装页。
2. 未授予「安装未知应用」时，是否停在引导页而不是点「安装」无声无息。
3. 设备直连 GitHub 不通时，是否如实报出「哪个候选 + 什么码」并自动换下一个。
4. 下载期间离开设置页再回来，进度是否还在；把 App 划掉则应当中断且不留半包。
5. 同一版本点「以后再说」后冷启动不再弹，出更高一版应当重新弹。
6. 画廊面板的「点不动」是偶发竞态：请多开几次「关于这张图」，尤其在打开后 3 秒内（译文与署名刚回填那阵）连点几枚标签。

## 仍未接的入口（是缺口，不是回归）

- **章节评论**面板、**追更**开关、**日志查看器**、**源分级逐源纠正**界面：代码在但入口未接，当前用不了。
- **Gelbooru 必须自备 API 凭据**（匿名取不到图）；**反向搜图**需自备 SauceNAO key（匿名过不去 Cloudflare）。
- **备份不含图片文件本身**：插图收藏只带元数据与地址，恢复后按地址现加载 —— 离线是裂图，部分源的地址带临时签名（几天后失效）。
- **WebDAV 是手动上传 / 恢复**，没有自动同步调度。
- 明确不做：Windows / Linux / macOS / iOS 的正式分发（本仓库的桌面线是实验分支）、EPUB / CBZ 直读、生物识别隐私锁、DoH。

完整清单见 [README 的「已知缺口与明确不做」](https://github.com/w13630039663-bit/venera-miuix/blob/compose-migration/README.md)。
