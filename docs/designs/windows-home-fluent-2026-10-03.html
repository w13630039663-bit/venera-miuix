骨架借 Windows，颜色借 Venera

中性 surface 阶梯、控件尺寸、圆角、焦点环、动效时长全部取 Fluent 官方口径；强调色仍由现有 MaterialKolor 种子色生成，两套色板互不替换。这样它"像 Windows 应用"，但仍是同一个 Venera。

首屏为"回来接着读"设计

桌面首页第一屏给继续阅读与内联详情，不给广告位。翻一部漫画不必离开首页——这条也顺手解掉评估文档里"跨窗口玻璃必然没有"的连带损失。

材质缺失要写明，不假装

系统 Mica/Acrylic 已实测画不出来（S0-6a 判负），本稿的顶栏与侧栏用应用内模糊加实底两级降级，界面上不出现"液态玻璃"字样。

1440 × 900 · 100% 缩放

交付前检查单

  • 无障碍：正文对比度 ≥ 4.5:1（本稿深色正文 #E4E4E4 / #202020 ≈ 13:1）；焦点环对所有可交互件可见；键盘顺序与视觉顺序一致；计数与状态不只靠颜色，另有文字（"2 连接失败"）。
  • 读屏：Compose Desktop 走 Java Access Bridge，打包已带 jdk.accessibility；文案只承诺 NVDA/JAWS 可读，不写"支持系统讲述人"。
  • 鼠标：hover 态不引起版面位移（动作行只在卡内展开）；可点件给 cursor；悬停揭示延时 350ms 防误触。
  • 触控：2in1 触控档最小触达 40×40（导航项与按钮已满足），封面卡的紧凑按钮 26 高在触控档要升到 36。
  • 降级可见：SauceNAO / mp4 / GIF / 材质 四项各有一条 InfoBar 或设置内说明文案，不留"能点但什么都不做"的控件。
  • 性能：首屏只解码可见封面；阅读统计迷你柱状用自绘不引图表库；动效全部走 transform/alpha。
  • 不做的东西：自动轮播、视差、真 3D、玻璃弹窗、跨窗口模糊、开机自启开关。
  • 与手机档的关系：本稿不改 Android 任何观感；共用的只有列数公式、断点定义、色板生成链路三处。

如果按这张稿开工，首页要分几刀

  1. 第 1 刀壳层：标题栏深色 + 侧栏 NavigationView（展开/收起/键盘 Ctrl B）+ 断点表落进 WideScreenPolicy，内容区先只放占位网格。不碰取数。
  2. 第 1 刀中性 surface 阶梯与字阶做成桌面侧 token 文件，与 Android 的 VeneraSpacing 并列而不服从它。
  3. 第 2 刀继续阅读 + 封面墙 hover 动作行 + 骨架 + InfoBar（接现有源健康读数）。这一刀完成后首页就能用。
  4. 第 3 刀右详情栏：需要"卡片 → 详情"的取数复用现成 EngineSession，并决定详情是预览还是可操作（本稿按可操作设计）。
  5. 第 4 刀键盘图与命令面板 Ctrl K、右键菜单全量、拖拽导入 CBZ、状态栏。
  6. 押后材质（haze 两级降级）、自绘窗饰、亮色档细校、2in1 触控档。

本稿的封面与作品名全为占位色块与虚构标题，不是素材也不是版权内容；真实封面在开发期由现成源出图替换。设计稿中"阅读统计""本地书架""漫画源"三块的名字与文案取自 feature/HomeScreen.kt 现网字符串，未新增模块。
